# ACT typography

## Font roles

Aqua Grotesque styles the Latin hero display only. The uploaded font file identifies Laura Pol / Pol Designs and copyright © 2014. The original binary stays unmodified at `src/assets/fonts/AquaGrotesque.ttf`. Its embedded font license permits embedding and redistribution with the copyright notice and complete license accompanying each distributed copy. The full notice is preserved in [`public/licenses/aqua-grotesque.txt`](../public/licenses/aqua-grotesque.txt). Mark confirmed permission for both self-hosted web use and distribution in ACT’s public repository. The source page describes the font as free for personal and commercial use, while the supplied file contains the detailed embedding and redistribution terms. [1] [2]

Alegreya Sans is the secondary typeface for body copy, headings, and supporting labels. The site uses the pinned `@fontsource/alegreya-sans` 5.3.0 package and loads only the Latin 400, 500, and 700 weights. The package and official Google Fonts source identify its license as SIL Open Font License 1.1. Its full notice ships at [`public/licenses/alegreya-sans-OFL.txt`](../public/licenses/alegreya-sans-OFL.txt). [3] [4]

Space Grotesk remains on the ACT wordmarks and the large decorative ACT art. IBM Plex Sans Thai stays in the font stacks after the English faces. Aqua Grotesque’s font map does not contain Thai, and Alegreya Sans does not list Thai in its official subsets, so the existing Thai package provides the script fallback. [4] [5]
